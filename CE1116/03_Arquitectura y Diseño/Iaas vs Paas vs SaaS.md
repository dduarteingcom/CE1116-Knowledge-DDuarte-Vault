## 📚 Idea/Concepto 

IaaS, PaaS y SaaS son modelos de servicio en el cloud que se diferencian por el nivel de abstracción y por cómo se reparten las responsabilidades entre proveedor y cliente.  
En IaaS el proveedor entrega cómputo, almacenamiento y red virtualizados, el cliente administra el sistema operativo, runtimes, parches, configuraciones de seguridad a nivel de SO y la aplicación que se ejecuta sobre máquinas virtuales, redes virtuales, discos, balanceadores, etc.  
En PaaS el proveedor también gestiona el sistema operativo, los runtimes y buena parte del middleware, exponiendo una plataforma lista para desplegar código, el cliente se centra en el desarrollo y configuración de la aplicación usando servicios como plataformas web, contenedores gestionados, funciones serverless o bases de datos gestionadas.  
En SaaS el proveedor entrega una aplicación completa consumida vía internet bajo suscripción; el cliente solo configura el producto y lo usa, mientras el proveedor se encarga de infraestructura, plataforma, parches, versiones, licencias y escalamiento según la demanda.  
En términos de control y esfuerzo operativo: IaaS ofrece mayor control con más carga de gestión, PaaS reduce significativamente la operación manteniendo flexibilidad de desarrollo y SaaS minimiza al máximo la administración a costa de una arquitectura subyacente poco personalizable.
